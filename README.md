🌟 GitHub Repository Description

Simple CLI Contact Book Manager is a lightweight, console-based utility developed entirely in Python to demonstrate fundamental programming concepts, including functions, control flow, and data structure manipulation. The application uses a Python dictionary to store contact information, where the contact's name serves as the unique key.

This project is excellent for developers learning core Python syntax and demonstrating proficiency in building practical, user-driven console tools.

Key Features:

    CRUD Functionality: Full Create, Read (View/List), Update, and Delete operations for contacts.

    Dictionary-Based Storage: Utilizes efficient key-value lookups (O(1) average time complexity) for quick contact management.

    Input Validation: Checks for empty names and existing contacts during the add operation.

    User-Friendly CLI: Clear, numbered menu system and distinct output for a smooth user experience.

    Safe Editing: The edit_contact function allows users to selectively update fields by providing current values and accepting blank input to keep existing data
